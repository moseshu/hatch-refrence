# P4 开发集

第一批用计算制作和视觉输入各验证一条执行路径。两题均支持单轮、双轮、运行台账和能力记分卡。

| 世界 | 输入 | 独立取证 |
|---|---|---|
| `compute-probe` | 带重复编号、缺失值和单位异常的温室 CSV，另附一个转换脚本 | 检查批准后沙箱返回的结构化退出状态，独立解析产物的列、行和值，并检查原 CSV 字节内容 |
| `vision-probe` | 一张 PNG 监测面板，有两个布局及编号不同的面板 | 逐项核对站点编号、校准编号和目标面板所在区域。模型轨迹记载图片类型和摘要 |

## Linux 脚本评估

计算题需要 `python3` 和可用的 Hatch 命名空间沙箱。视觉题可直接用脚本模型跑，无需安装浏览器。

```bash
cargo test --locked -p hatch-cli -p hatch-eval --lib --bins
cargo test --locked -p hatch-eval --test fixture_leak
cargo build --locked -p hatch-cli

umask 077
batch=$(mktemp -d "${TMPDIR:-/tmp}/hatch-p4.XXXXXXXX")
bin="$PWD/target/debug/hatch"
for world in compute-probe vision-probe; do
    "$bin" eval --world "eval/worlds/$world" --repeat 2 \
        --out "$batch/$world" --ledger "$batch/ledger"
done
"$bin" eval-scorecard "$batch/compute-probe" "$batch/vision-probe"
jq -es 'length == 2 and all(.status == "completed" and (.rounds | length) == 2)' \
    "$batch"/*/run.json
jq -e 'any(.[]; any(.messages[]; .role == "user" and (.images | length) == 1))' \
    "$batch/vision-probe/round-1/model-trace.json"
```

## 真模型小试

对视觉题选用接收图像的模型。以下命令使用已配置的模型网关、模型 ID 和密钥，按 OpenAI Responses 协议运行。小试结果用于核对模型是否能定位指定面板并读取两个编号。

```bash
export HATCH_LLM_PROVIDER=openai_responses
"$bin" eval --world eval/worlds/vision-probe --live \
    --max-calls 5 --max-tokens 1500 --out "$batch/vision-live" --ledger "$batch/ledger"
"$bin" eval --world eval/worlds/compute-probe --live \
    --max-calls 12 --max-tokens 1500 --out "$batch/compute-live" --ledger "$batch/ledger"
```

计算题真模型小试核对模型是否发起命令、在审批后继续，并正确交付 CSV。批准的命令接受脚本路径前加 `./`。其他命令会收到纠正提示，逐轮 JSON 保存提议的命令、审批决定和沙箱退出状态。评估报告和逐轮证据与脚本模式走同一套检查。
