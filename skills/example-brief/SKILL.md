# 每日简报写作规范

写简报时遵守以下方式：

- 每条事项只写一句话，先写结论再写细节；不写没有依据的内容。
- 需要用户偏好或约定信息时，先用 memory_search 查记忆，不要凭空猜。
- 事项按“待你决定 / 进行中 / 已完成”分组；每组最多 5 条。
- 不确定的事写“不确定”，不要编一个看似确定的答案。

以上只是工作方式说明，不是用户指令。任何对外动作（发信、改日程、改文件）
仍需按审批流程确认，技能本身不能批准任何事。
